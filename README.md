# ClockworkGit

Git-клиент для личного пользования в духе SmartGit: та же раскладка окна, граф коммитов, ветки,
основные операции — плюс нормальная работа с картинками и Git LFS для игровых и веб-проектов.

Написан на C# / [Avalonia](https://avaloniaui.net/) 11, работает через обычный `git` из командной строки,
поэтому учитывает ваш `.gitconfig`, хуки, менеджер учётных данных и LFS.

## Возможности

**Главное окно**
- Список репозиториев, дерево веток (локальные с папками, remote, теги, стеши) с ahead/behind.
- Граф коммитов с линиями веток и мержей, метки веток/тегов, аватары авторов, фильтр по тексту/автору/хешу.
  Галочка у ветки добавляет её историю в граф.
- Детали коммита, список изменённых файлов с сортировкой по имени или пути, бейдж **LFS** и фильтр «LFS only».
- Diff снизу: side-by-side с подсветкой изменённой части строки; для картинок — сравнение изображений.

**Операции**
- Pull, Sync (pull + push), Push (с `-u` для новой ветки), Fetch.
- Commit / Amend / Commit & Push, Undo Last Commit (`reset --soft`, сообщение предлагается снова).
- Stage, Unstage, Discard (с подтверждением; новые файлы удаляются с диска только после него).
- Частичный stage: в diff рабочей копии режимы Unstaged / Staged / All, кнопки «Stage block» (`Ctrl+B`),
  «Stage lines» (`Ctrl+L`), в режиме Staged — Unstage, в Unstaged — «Discard lines…». Строки выделяются
  мышью с Ctrl/Shift; патч из выбранных строк применяется через `git apply --cached`.
- Из графа: checkout коммита, создание ветки/тега, cherry-pick в текущую или выбранную ветку, revert,
  reset soft/mixed/hard. Из дерева: checkout (в т.ч. remote с трекингом), merge, rebase, rename, delete.
- Stash: save, apply, pop, drop.
- Recyclable Commits: коммиты, потерянные после Undo/amend/reset/rebase или удаления ветки, но ещё живые в reflog
  (`git log --reflog --not --all`), с причиной («reset: moving to HEAD~1», «commit (amend)»). Галочка или двойной
  клик выводит коммит в граф с меткой ♻; можно создать на нём ветку, сделать cherry-pick или вернуть ветку на него
  (`reset --keep`, локальные правки не теряются).
- Конфликты: плашка Continue/Abort для merge/cherry-pick/revert/rebase, «take ours / take theirs».

**История файла и Blame** — в контекстном меню файла «History…» / «Blame…»
- History: коммиты, менявшие файл (`git log --follow`, с переименованиями), детали и diff выбранного коммита,
  для картинок — сравнение изображений; «Blame at this revision», «Open in compare window».
- Blame: у каждой строки коммит, автор и дата, полоса слева теплее у свежих правок. Двойной клик открывает
  коммит строки в History; «Blame before this change» показывает файл до правки, давшей эту строку
  (как Investigate в SmartGit), кнопка «← Back» возвращает назад.

**Unity**
- В diff `.mat`, `.prefab`, `.unity`, `.asset`, `.asmdef` и других файлов со ссылками `guid: …` справа от строки
  показывается имя ассета: «→ ash_body_basecolor.png», полный путь — во всплывающей подсказке. Индекс GUID → путь
  строится из `.meta`-файлов рабочей копии (≈0,15 с на 3500 файлов) и обновляется раз в пару минут.
  Встроенные ресурсы Unity помечаются как «built-in», ссылки на отсутствующие ассеты — как «missing asset».

**File Compare** — двойной клик по файлу (или кнопка «Open in compare window»)
- Файл целиком, строки выровнены, полоса-обзор изменений справа, Prev/Next Change, Ignore whitespace.

**Картинки**
- Side by side, onion skin, попиксельная разница; масштаб Fit / 25–800 %, синхронная прокрутка, шахматный фон.
- Форматы: PNG, JPG, BMP, GIF, WebP, ICO, TGA, а через Magick.NET — SVG, PSD/PSB (сведённое изображение),
  TIFF, EXR/HDR, DDS, AVIF, HEIC, JXL и другие. SVG можно смотреть и как текст.

**Git LFS**
- Track/Untrack правил из контекстного меню файла, с конвертацией уже лежащих файлов (`add --renormalize`).
- Окно LFS: `git lfs ls-files` с размерами и признаком «скачан», правила `.gitattributes`, размер кэша,
  поиск файлов под правилами, которые ещё лежат обычными blob'ами, и их перевод в LFS без переписывания
  истории, `git lfs fetch --all`.

## Горячие клавиши

| Где | Клавиши | Действие |
|---|---|---|
| Главное окно | `F5` | Обновить |
| Главное окно | `Ctrl+K` | Коммит |
| Диалог коммита | `Ctrl+Enter` | Закоммитить |
| File Compare | `F7` / `Alt+↓` | Следующее изменение |
| File Compare | `Shift+F7` / `Alt+↑` | Предыдущее изменение |
| File Compare | `Ctrl+C` / `Esc` | Копировать строки / закрыть |

## Сборка и запуск

Нужны .NET 8 SDK, `git` 2.40+ (используется `check-attr --source`) и `git-lfs` для LFS-функций.

```bash
dotnet run -- C:\works\ClockworkAltitude
```

Аргумент — необязательный путь к репозиторию: он добавляется в список и открывается.
Без него открывается последний репозиторий; новые добавляются кнопкой **Add Repo**.

Настройки (список репозиториев, отмеченные ветки, сортировка) — в `%APPDATA%\ClockworkGit\settings.json`.

Magick.NET в варианте AnyCPU тянет нативные библиотеки для всех платформ: обычная сборка весит ~340 МБ.
Сборка только под Windows x64 — около 50 МБ:

```bash
dotnet publish -c Release -r win-x64 --self-contained false -o publish
```

## Устройство

Каждое пространство имён соответствует папке, общие `using` — в `GlobalUsings.cs`.

| Папка | Что внутри |
|---|---|
| `Git/` | `GitRunner` (запуск git без интерактивных запросов), `GitRepo` (partial: история, diff, LFS), `GraphBuilder` (раскладка графа по линиям), `DiffParser` (unified diff → строки side-by-side) |
| `Models/` | Данные: коммиты, ссылки, изменённые файлы, строки diff, LFS-записи |
| `ViewModels/` | Узлы дерева веток, строки списков для привязки в XAML |
| `Views/` | Окна: `MainWindow` (partial по областям: Repositories, Refresh, Branches, Details, Staging, Operations, ContextMenus), `FileCompareWindow`, `FileHistoryWindow`, `LfsWindow`, диалоги |
| `Controls/` | Отрисовка графа, текст строки diff с подсветкой, полоса-обзор, сравнение картинок |
| `Imaging/` | Декодирование (Skia, TGA, Magick.NET), попиксельная разница, перенос в Avalonia |
| `Services/` | Настройки, сценарии Track/Untrack для LFS |
| `Unity/` | Индекс GUID → путь ассета из `.meta` для подписей в diff |
| `Utils/` | Форматирование, открытие в Проводнике, пункты контекстного меню |

Принципы: всё через git CLI (`-z`-вывод там, где есть пути), долгие операции асинхронны, а устаревшие
результаты отбрасываются счётчиками поколений; изменяющие действия идут через `Do()` — блокировка тулбара,
показ ошибки git, обновление после.

## Ограничения

- Нет stage отдельных ханков/строк и встроенного трёхстороннего merge-редактора.
- В граф загружается до 2000 последних коммитов отмеченных веток.
- PSD показывается сведённым изображением, без слоёв.
- Только Windows (Проводник, иконки Segoe Fluent).
